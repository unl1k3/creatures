# Bevy Blob

A 2D vertical-platformer prototype written in Rust with Bevy 0.19. The player
controls a deformable soft-body creature that can roll, charge jumps, split into
independent fragments, merge back together, and emit radial bursts of acid.

The active game project is located in [`bevy_blob/`](bevy_blob/).

## Quick Start

```bash
cd bevy_blob
cargo run
```

Run the automated test suite with:

```bash
cd bevy_blob
cargo test
```

See the [complete Bevy Blob documentation](bevy_blob/README.md) for controls,
gameplay mechanics, architecture, project layout, and roadmap.
